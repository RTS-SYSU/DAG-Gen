# Web UI 使用说明

## 概述

Web UI 是 Runtime Compare Tool 的 Web 界面，适合在远程设备（如 RK3588 板子）上使用，通过浏览器访问，提供便捷的任务配置和管理功能。

## 启动 Web 服务器

### 基本启动

```bash
python3 tools/runtime_compare/main.py --web
```

默认监听地址：`http://0.0.0.0:5000`

### 自定义端口和地址

```bash
python3 tools/runtime_compare/main.py --web --host 0.0.0.0 --port 8080
```

### 启用排队模式

```bash
python3 tools/runtime_compare/main.py --web --queue-mode
```

排队模式下，所有任务串行执行，确保严格隔离。

## 访问界面

启动服务器后，在浏览器中访问：

```
http://<服务器IP>:5000
```

例如，如果服务器在本地：
```
http://localhost:5000
```

如果在远程设备（如 RK3588）：
```
http://<设备IP>:5000
```

## 功能说明

### 1. 系统信息

页面顶部显示系统信息：
- **在线 CPU**：显示所有可用的 CPU 核心列表
- **空闲 CPU**：当前空闲的核心数量
- **排队模式**：是否启用串行执行模式
- **连接状态**：页面右上角的绿色/红色圆点表示连接状态

### 2. 配置文件管理

#### 配置文件列表

显示所有已保存的配置文件，包括：
- 文件名
- 文件大小
- 修改时间
- 操作按钮（下载、删除）

#### 导出配置文件

有两种导出方式：

1. **自动导出**：添加任务后自动保存配置文件
   - 如果指定了"配置名称"，使用该名称
   - 否则自动命名为 `web_tasks_<timestamp>.json`

2. **手动导出**：点击"导出当前配置"按钮
   - 可以指定配置文件名
   - 导出当前所有任务

#### 导入配置文件

1. 点击"导入配置文件"按钮
2. 选择 JSON 格式的配置文件
3. 系统会自动解析并添加任务（去重检查）

#### 下载配置文件

点击配置文件列表中的"下载"按钮，可以下载配置文件到本地。

#### 删除配置文件

点击配置文件列表中的"删除"按钮，可以删除不需要的配置文件。

### 3. 添加新任务

#### 任务表单字段

- **配置名称（可选）**：用于命名导出的配置文件
- **Baseline C 文件**：baseline 版本的 C 文件路径（绝对路径或相对路径）
- **Prio C 文件**：priority 版本的 C 文件路径
- **WORK_SCALE**：工作规模参数（默认：25000）
- **重复次数**：每个程序运行的重复次数（默认：1）
- **每任务核数**：每个任务使用的 CPU 核心数（默认：1）
- **CPU 核心列表（可选）**：手动指定 CPU 核心，格式如 `4,5,6,7`（留空则自动分配）
- **使用 sudo 运行**：是否使用 sudo 权限运行（需要配置免密 sudo）

#### 添加任务流程

1. 填写任务表单
2. 点击"添加任务"按钮
3. 任务自动加入队列并开始执行
4. 配置文件自动导出到 `tools/runtime_compare/配置文件/` 目录

### 4. 任务列表

#### 任务状态

- **queued**（等待中）：任务已加入队列，等待执行
- **running**（运行中）：任务正在执行
- **done**（已完成）：任务执行成功
- **error**（错误）：任务执行失败
- **cancelled**（已取消）：任务被取消

#### 任务信息显示

- **任务ID**：唯一标识符
- **状态**：当前任务状态
- **阶段**：当前执行阶段（setup, copy, compile, run, done）
- **进度**：显示进度条和百分比
- **CPU**：分配的 CPU 核心列表
- **耗时**：任务执行时间
- **消息**：任务状态消息
- **操作**：可执行的操作按钮

#### 任务操作

- **详情**：展开/收起任务详细信息
- **取消**：取消等待中的任务（仅 queued 状态）
- **查看日志**：查看任务的运行日志
- **结果目录**：显示任务结果目录路径

#### 任务筛选

使用"筛选状态"下拉菜单可以按状态筛选任务：
- 全部
- 等待中
- 运行中
- 已完成
- 错误
- 已取消

### 5. 实时更新

页面每 2 秒自动刷新任务列表和系统信息，无需手动刷新。

连接状态指示器会显示当前连接状态：
- 🟢 绿色：在线
- 🔴 红色：离线

## 使用场景

### 场景 1：远程设备配置任务

1. 在 RK3588 板子上启动 Web 服务器：
   ```bash
   python3 tools/runtime_compare/main.py --web --host 0.0.0.0
   ```

2. 在本地浏览器访问：
   ```
   http://<板子IP>:5000
   ```

3. 在 Web 界面配置任务并添加

4. 任务自动导出配置文件

5. 即使断网，也可以使用 CLI 加载配置文件继续执行

### 场景 2：批量任务管理

1. 在 Web 界面添加多个任务
2. 所有任务自动保存到配置文件
3. 可以手动导出配置文件备份
4. 可以导入之前保存的配置文件恢复任务

### 场景 3：任务监控

1. 启动 Web 服务器
2. 在浏览器中打开界面
3. 实时查看任务执行状态和进度
4. 查看任务日志和结果

## 配置文件格式

Web UI 导出的配置文件格式与 CLI 模式兼容：

```json
{
  "tasks": [
    {
      "baseline_c": "/path/to/baseline.c",
      "prio_c": "/path/to/prio.c",
      "work_scale": 25000,
      "repeats": 3,
      "cores_per_task": 4,
      "cpu_list": [4, 5, 6, 7],
      "use_sudo": false
    }
  ],
  "queue_mode": false,
  "created_at": "2026-02-02T10:30:00"
}
```

## 结果文件

任务完成后，结果保存在：

```
tools/runtime_compare/实验结果/<config_name>/<timestamp>_ws<work_scale>_r<repeats>/
├── summary.json          # 统计信息和元数据
├── run.log               # 完整运行日志
├── runs.csv              # 每次运行的耗时表
├── run_results_*.txt     # 三段式文本报告
├── baseline/             # baseline 编译结果
└── prio/                 # prio 编译结果
```

## 注意事项

1. **文件路径**：
   - 建议使用绝对路径
   - 相对路径相对于服务器的工作目录

2. **CPU 核心分配**：
   - 确保 `cores_per_task` 不超过可用核心数
   - 如果指定了 `cpu_list`，优先使用指定的核心

3. **权限问题**：
   - 如果启用 `use_sudo`，需要配置免密 sudo
   - 确保 Web 服务器用户有写入结果目录的权限

4. **网络访问**：
   - 默认监听 `0.0.0.0`，可以从任何 IP 访问
   - 如需限制访问，可以绑定到特定 IP

5. **配置文件存储**：
   - 配置文件保存在 `tools/runtime_compare/配置文件/` 目录
   - 建议定期备份配置文件

6. **任务去重**：
   - 导入配置文件时会自动去重
   - 相同参数的任务不会重复添加

## 故障排除

### 问题 1：无法访问 Web 界面

**解决方案**：
- 检查服务器是否正常启动
- 检查防火墙设置
- 确认 IP 地址和端口正确

### 问题 2：任务添加失败

**解决方案**：
- 检查 C 文件路径是否正确
- 确认文件存在且有读取权限
- 查看浏览器控制台的错误信息

### 问题 3：配置文件导出失败

**解决方案**：
- 检查 `tools/runtime_compare/配置文件/` 目录权限
- 确认有写入权限
- 查看服务器日志

### 问题 4：任务执行失败

**解决方案**：
- 查看任务日志（点击"查看日志"按钮）
- 检查 CPU 核心是否足够
- 确认编译和运行环境正确

## API 接口

Web UI 提供以下 RESTful API（供高级用户使用）：

- `GET /api/system` - 获取系统信息
- `GET /api/tasks` - 获取所有任务
- `POST /api/tasks` - 添加新任务
- `DELETE /api/tasks/<task_id>` - 取消任务
- `GET /api/tasks/<task_id>/log` - 获取任务日志
- `GET /api/config/list` - 列出配置文件
- `GET /api/config/download/<filename>` - 下载配置文件
- `DELETE /api/config/delete/<filename>` - 删除配置文件
- `POST /api/config/export` - 导出配置文件
- `POST /api/config/import` - 导入配置文件

## 与 CLI 模式的配合使用

1. **在 Web UI 中配置任务**：
   - 添加任务后自动导出配置文件

2. **使用 CLI 加载配置**：
   ```bash
   python3 tools/runtime_compare/main.py --cli --config tools/runtime_compare/配置文件/web_tasks_xxx.json --wait
   ```

3. **断网后继续执行**：
   - Web UI 导出的配置文件可以在离线环境下使用 CLI 执行
   - 适合网络不稳定的环境
