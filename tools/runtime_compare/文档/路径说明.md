## Python 导入路径

### 从项目根目录运行

```python
# 正确
from tools.runtime_compare.core.task import Task
from tools.runtime_compare.utils.cpu import read_cpu_online
```

### 从 tools/runtime_compare 目录运行

需要将项目根目录添加到 `sys.path`：

```python
import sys
from pathlib import Path
project_root = Path(__file__).parent.parent.parent
sys.path.insert(0, str(project_root))

from tools.runtime_compare.core.task import Task
```

## 配置文件路径

配置文件可以使用绝对路径或相对路径：

```json
{
  "tasks": [
    {
      "baseline_c": "/absolute/path/to/baseline.c",  // 绝对路径
      "prio_c": "relative/path/to/prio.c"            // 相对路径（相对于当前工作目录）
    }
  ]
}
```

## 结果输出路径

结果保存在：
```
tools/runtime_compare/实验结果/<config_name>/<timestamp>_ws<work_scale>_r<repeats>/
├── summary.json          # 统计结果和元信息
├── runs.csv              # 每次运行的耗时表
├── run.log               # 完整输出日志
├── run_results_*.txt     # 三段式文本报告
├── baseline/             # baseline 编译结果
└── prio/                 # prio 编译结果
```

其中 `<config_name>` 为配置文件名（不含扩展名），如果未指定则默认为 "experiment"。

## 配置文件路径

配置文件保存在：
```
tools/runtime_compare/配置文件/
└── <config_name>.json
```

配置文件可以使用绝对路径或相对路径（相对于当前工作目录）。

## 日志路径

- CLI 日志：`tools/runtime_compare/实验结果/logs/cli.log`
- 任务日志：每个任务的结果目录中的 `run.log`

## 常见问题

### Q: 导入错误 `ModuleNotFoundError: No module named 'tools.runtime_compare'`

**A:** 确保从项目根目录执行，或正确设置 `sys.path`。

### Q: 找不到配置文件

**A:** 使用绝对路径，或确保相对路径相对于当前工作目录正确。

### Q: 结果目录权限错误

**A:** 使用 `--queue-mode` 和 `use_sudo: true`，或确保有写入权限。

### Q: 配置文件保存在哪里？

**A:** 配置文件保存在 `tools/runtime_compare/配置文件/` 目录。Web UI 会自动导出配置文件，CLI 模式也可以手动指定配置文件路径。

### Q: 如何找到实验结果？

**A:** 实验结果保存在 `tools/runtime_compare/实验结果/<config_name>/<timestamp>_ws<work_scale>_r<repeats>/` 目录下。每个任务的结果包括 summary.json、runs.csv、run.log 和 run_results.txt 文件。
