# zhang1 五算法 runtime 与程序体内手动测时校验（ws=100）

## 1. 实验目的

验证 `runtime_compare` 工具在 `work_scale=100` 下，对 zhang1 的全部 5 个调度算法（cpf、heft、zhao2020、wcet_first、t_level）的测时结果是否与程序体内手动计时口径一致。

## 2. 两种测时方法说明

### 2.1 runtime_compare 工具测时（wrap_main 机制）

原理：

1. 编译时使用 `-Wl,--wrap=main`，将 `main()` 入口重定向到 `__wrap_main()`
2. `__wrap_main()` 中调用 `l1_prog_begin()` 记录起始时间戳
3. 然后调用 `__real_main()`（即原始 `main()`）
4. 通过 `atexit(l1_prog_end)` 注册退出回调
5. 程序退出时 `l1_prog_end()` 计算耗时，输出 `PROGRAM_TOTAL_NS=<纳秒>` 到 stderr
6. Python 端从 stderr 解析该值

涉及文件：

- `level1/wrap_main.c` — `__wrap_main()` 入口包装
- `level1/prog_timer.c` — `l1_prog_begin()` / `l1_prog_end()`，使用 `clock_gettime(CLOCK_MONOTONIC_RAW)`
- `level1/prog_timer.h` — 头文件
- `tools/runtime_compare/utils/time_parse.py` — 解析 `PROGRAM_TOTAL_NS=(\d+)`

编译命令：

```bash
gcc -O0 -g -std=c11 -pthread -Wl,--wrap=main -lm \
    -I<src_dir> -I<level1> -DWORK_SCALE=<ws> \
    source_original.c wrap_main.c prog_timer.c -o app_baseline
```

### 2.2 程序体内手动测时（inject_main_timer）

原理：

1. 在 `main()` 函数体的第一行注入 `uint64_t __prog_t0_ns = my_now_ns();`
2. 在 `return 0;` 之前注入 `fprintf(stderr, "PROGRAM_TOTAL_NS=%llu\n", ...);`
3. `my_now_ns()` 使用 `clock_gettime(CLOCK_MONOTONIC_RAW)` 获取纳秒时间戳
4. 编译时不使用 `--wrap=main`，不链接 `wrap_main.c` / `prog_timer.c`
5. 直接编译运行，从 stderr 解析 `PROGRAM_TOTAL_NS`

注入的辅助函数：

```c
static uint64_t my_now_ns(void) {
  struct timespec ts;
#ifdef CLOCK_MONOTONIC_RAW
  clock_gettime(CLOCK_MONOTONIC_RAW, &ts);
#else
  clock_gettime(CLOCK_MONOTONIC, &ts);
#endif
  return (uint64_t)ts.tv_sec * 1000000000ULL + (uint64_t)ts.tv_nsec;
}
```

编译命令：

```bash
gcc -O0 -g -std=c11 -pthread -lm \
    -I<src_dir> -DWORK_SCALE=<ws> \
    source_original.c -o app_baseline
```

### 2.3 两种方法的区别

| 项目 | runtime_compare | 手动测时 |
|------|----------------|---------|
| 计时起点 | `__wrap_main()` 入口 | `main()` 函数体第一行 |
| 计时终点 | `atexit` 回调 | `return 0` 之前 |
| 时钟源 | `CLOCK_MONOTONIC_RAW` | `CLOCK_MONOTONIC_RAW` |
| 额外链接 | `wrap_main.c` + `prog_timer.c` | 无 |
| 链接器选项 | `-Wl,--wrap=main` | 无 |

理论上两者测量的时间范围几乎相同（都是 main 函数的执行时间），偏差应在 5% 以内。

## 3. 本次实验配置

- 测试用例：`zhang1`
- 算法：`cpf`、`heft`、`zhao2020`、`wcet_first`、`t_level`
- `work_scale = 100`
- `repeats = 10`（每个算法的 baseline 和 prio 各跑 10 次）
- `cpu_set = [0, 1]`
- `cores_per_task = 2`
- `use_sudo = false`

## 4. 实验流程

对每个算法（共 5 个），分别执行：

1. **手动测时**：
   - 取 `source_original.c`（baseline）和 `source_instrumented.c`（prio）
   - 注入 `my_now_ns()` 计时代码
   - 编译（不用 `--wrap=main`）
   - 绑核 [0,1] 运行 10 次
   - 收集 `PROGRAM_TOTAL_NS`

2. **runtime_compare 工具测时**：
   - 生成 JSON 配置文件
   - 调用 `tools/runtime_compare/main.py --cli --wait`
   - 从 `summary.json` 读取结果

3. **对比**：
   - 计算手动均值 vs runtime 均值的偏差百分比
   - 输出对比表格
