# 源码调用图使用说明（extern 过滤版）

本文记录近期对“生成源码调用图”功能的改动与使用方式，便于制作汇报 PPT 和日后维护。

## 功能概览
- 从 `.expand` 解析函数调用关系，并结合选中的源文件，标记 `mycalls_meta` 中每条调用的 `extern` 字段（仅比较文件名）。
- 在生成源码调用图时，仅输出 `extern == 1` 的调用节点/边，其他调用跳过。
- 自动渲染过滤后的 `.dot` 为 `.png`。
- GUI 右侧新增统计栏，显示：
  - `源代码函数调用：<extern==1 数量>`
  - `外部函数调用：<extern==0 数量>`
- GUI 源码调用图子功能按钮（顺序）：
  1. 查看源代码（系统默认编辑器打开选中的源文件）
  2. 查看 expand 文件（系统默认编辑器打开选中的 expand）
  3. 查看函数对应表（打开 `debug/mycalls_meta.json`）
- 调试输出：在中间结果目录下 `生成dag图/debug/` 保存 `functions_debug.json` 与 `mycalls_meta.json`。

## 生成入口（GUI 2.1 按钮）
1. 依次选择源文件与 expand 文件（左侧按钮 1, 1.5）。
2. 点击“2.1 生成源码调用图”。
3. 程序自动调用 `mycallyplus.generation.legacy --extern-only`，输出文件位于：
   - `中间结果/<基名>/生成dag图/dag_source_only.dot`
   - `中间结果/<基名>/生成dag图/dag_source_only_filt.dot`
   - `中间结果/<基名>/生成dag图/dag_source_only_filt.png`
   - `中间结果/<基名>/生成dag图/debug/functions_debug.json`
   - `中间结果/<基名>/生成dag图/debug/mycalls_meta.json`
4. 右侧展示区显示 `dag_source_only_filt.png`，并在图片上方显示 extern 统计。
5. 右侧子功能栏出现 3 个按钮（查看源代码 / expand / 函数对应表）。

## 过滤与统计逻辑
- `extern` 判定：仅按文件名比较选中的源文件与 `mycalls_meta[*].file` 的 basename；相同则 `extern=1`，否则 `extern=0`。
- `--extern-only`：在生成 `.dot` 时只输出 `extern==1` 的调用节点/边。
- 统计：遍历 `debug/mycalls_meta.json`，`extern==1` 记为“源代码函数调用”，其余为“外部函数调用”。

## 调试与存储路径
- 统一使用 mycallyplus 根下的中间结果目录：`mycallyplus/中间结果/<基名>/生成dag图/`。
- `debug/` 目录内：
  - `functions_debug.json`：完整 `functions` 数据结构（序列化版本）。
  - `mycalls_meta.json`：调用到源代码位置的映射（含 `file/line/col/extern`）。
  - 其他阶段性快照由 `_dump_debug_*` 输出（带时间戳）。

## CLI 调用示例
```bash
python3 -m mycallyplus.generation.legacy \
  --extern-only \
  --source-file mycallyplus/源文件/FixedwingRateControl/FixedwingRateControl.cpp \
  mycallyplus/源文件/FixedwingRateControl/FixedwingRateControldemangled.cpp.233r.expand
```
输出同样位于 `中间结果/<基名>/生成dag图/`。

## 代码改动概要
- `legacy.py`
  - `--extern-only`：过滤 `extern==1` 的调用生成 `.dot`。
  - 调试输出：`生成dag图/debug/` 下落盘 `functions_debug.json` 和 `mycalls_meta.json`。
- `ui/gui.py`
  - 增加源码调用图统计栏；生成源码调用图时显示 extern 计数。
  - 子功能按钮：查看源代码、查看 expand、查看 `mycalls_meta.json`。
  - 生成源码调用图入口改用 `legacy --extern-only` 并写入 `dag_source_only*.dot/png`。

## 使用建议
- 若图中仍有大量外部节点，可检查 `mycalls_meta.json` 的 `file` 字段与选中源文件名是否一致，必要时调整 `extern` 判定策略。
- 确保已安装 Graphviz（提供 `dot` 命令）以正常渲染 PNG。***
