# 04. 数据流与存储机制

## 4.1 目录总览
```
中间结果/<base>/
├── 配置文件/                  # 最终 DOT / circle / expand / 源码
├── 生成dag图/
│   ├── dag.dot / dag.png
│   └── debug/ (functions_full, mycalls_meta*, call_src_full, time_analysis.log…)
├── 查看条件节点/             # conditions.dot/png
├── 生成源码调用图/
├── 查看互斥锁/
├── 生成信号量图/
├── 时间分析/<project>/        # 插桩工程、time_result.json、thread_trace.json…
├── 时间分析_lp/<project>/     # （建议）最长路径插桩结果
├── 调度算法/<strategy>/       # dag_highlight、schedule.json/txt
└── 其它（logs/temp/images 等）
```

> 旧版 `配置文件/<base>/` 不再写入，仅作为读取兼容存在。

## 4.2 配置文件目录 `中间结果/<base>/配置文件/`
- `<base>.dot`（默认）
- `<base>_threads.dot`（threads-only）
- `<base>_full.dot`（conditions-only）
- `circle.txt`
- `<base>.c`（可选，若 `--source-file`）
- `<base>.c.233r.expand`
- `debug/<timestamp>_post_*.json`（legacy 在配置目录下也会留快照）

## 4.3 生成 DAG / 条件节点
- `生成dag图/`：`dag.dot/png` + `debug/` 内的 `functions_full.json`、`mycalls_meta*.json`、`time_analysis.log` 等。
- `查看条件节点/`：`conditions.dot/png`。

## 4.4 时间分析
- `中间结果/<base>/时间分析/<project>/`
  - `time_result.json`
  - `thread_trace.json`
  - `time_stat.c/h`、`app`、插桩后的源码
- `中间结果/<base>/生成dag图/debug/mycalls_meta_internal.json`：时间分析输入
- 建议 `时间分析_lp/<project>/` 存放“最长路径插桩”后的专项结果。

## 4.5 调度算法
- 默认示例：`中间结果/time_analysis/调度算法/longest_path/`
  - `dag_highlight.dot/png`
  - `longest_path.json/txt`
- 自定义策略：放在 `调度算法/<strategy>/`
  - `dag_highlight.dot/png`
  - `schedule.json/txt`
  - 可附加 `compare.json` 汇总多策略对比
- `longest_path_compare.{json,txt}`（建议用于插桩前后对比）

## 4.6 调试快照
- `中间结果/<base>/生成dag图/debug/`
  - `functions_full.json`
  - `functions_debug.json`
  - `mycalls_meta.json`
  - `mycalls_meta_internal.json`
  - `call_src_full.json`
  - `thread_time_summary.json`
  - `time_analysis.log`
  - `<timestamp>_post_parse.json` / `_control_prefix.json` / `_post_callee_info.json` / `_threads.json`

这些快照有助于定位解析问题、条件前缀、线程补边等。

## 4.7 数据流示意
1. **生成**：`expand` → legacy → `配置文件/<base>/...` + `生成dag图/` + `debug/`
2. **GUI/Viewer**：从 `配置文件/` 读取 DOT/TXT → 按功能复制/渲染到相应目录
3. **时间分析**：`mycalls_meta_internal.json` + 源码 → `时间分析/<project>/time_result.json`
4. **调度策略**：`dag.dot` + `time_result.json` + `longest_path.json` → `调度算法/<strategy>/dag_highlight.dot/png`
5. **插桩对比**：`时间分析_lp` 与 `时间分析` 输出 → `调度算法/longest_path_compare.json`

通过 `04` 章节掌握目录/文件命名后，可对照 `03`/`05`/`06` 理解各功能产生的数据与依赖关系。***
