# 02. 模块与依赖

| 模块 | 关键文件/目录 | 主要职责 | 关键依赖 |
| ---- | ------------- | -------- | -------- |
| **generation** | `generation/legacy.py`、`generation/thread_map.py`、`generation/exporters.py` | 解析 `.expand`、构建函数图、条件前缀、线程补边、导出 DOT/circle/debug。 | `re`、`json`、`thread_map`、`source_binder` |
| **ui/gui** | `ui/gui.py` | 统一 GUI 按钮：生成 DAG、条件节点、源码调用图、互斥锁、信号量、时间分析、调度算法、过滤 DOT、选择配置文件等。 | `tkinter`、`subprocess`、`scheduler`、`time_analysis` |
| **ui/generation_gui** | `ui/generation_gui.py` | 早期/辅助 GUI，支持批量生成配置文件（保留兼容）。 | `legacy` |
| **visualization** | `visualization/viewer.py` | 独立查看器（原始图、互斥锁图、信号量图、Tarjan、线程视图）。 | `tkinter`、`networkx`、`subprocess` |
| **time_analysis** | `time_analysis.py`、`source_only.py` | 基于 `mycalls_meta_internal.json` 自动插桩、编译、运行，生成 `time_result.json`、`thread_trace.json`、`thread_time_summary.json`。 | `gcc`、`shutil`、`json` |
| **scheduler** | `scheduler.py` | DOT 解析、最长路径、调度策略、带权高亮、highlight_patch、longest_path_compare。 | `re`、`json` |
| **docs** | `文档/` | GUI 按键、源码调用图说明、Run_block_calls、调度算法方案等。 | - |

## 2.1 generation（legacy）
- CLI 参数详见 `legacy.py:main()`。
- `_ensure_output_dirs`：已调整为输出至 `中间结果/<base>/配置文件/`。
- `full_call_graph()`、`conditions_call_graph()`：输出 DOT。
- 调试快照 `_dump_debug_snapshot()`：`中间结果/<base>/生成dag图/debug/<timestamp>_*.json`。
- 互斥锁/信号量需要 `circle.txt`（由 `--export-txt` 生成）。

## 2.2 GUI (ui/gui.py)
关键成员：
- `FileState`：跟踪当前源/expand/dot/txt/work_dir。
- `_config_dir_for_base` / `_iter_config_dirs`：定位配置目录（新结构）。
- `generate_dag()` / `view_conditions()` / `generate_source_only_dag()`：分别处理 threads/full/source-only DOT。
- `view_mutex()` / `generate_semaphore()`：依赖 `circle.txt`。
- `time_analysis_entry()`：驱动 `time_analysis.run_time_analysis()`。
- `scheduler_entry()`：包含“生成最长路径”与后续扩展子功能。

## 2.3 viewer
- 默认配置目录：`中间结果/<base>/配置文件/`，兼容旧 `配置文件/<base>/`。
- 主要功能：load dot/txt、生成 PNG、Tarjan 分析、互斥锁/信号量查看。

## 2.4 time_analysis
- `load_call_sites()`：解析 `mycalls_meta_internal.json`。
- `run_time_analysis()`：复制项目 → 插桩 → 编译 → 运行 → 写 `time_result.json`、`thread_trace.json`（现已支持 `thread_trace` 用于甘特图/调度）。
- 日志写入：`中间结果/<base>/生成dag图/debug/time_analysis.log`。

## 2.5 scheduler
- `parse_dot_edges()`：简单正则解析 DOT。
- `longest_path_dag()`：拓扑 + DP（有环时报错）。
- `highlight_dot_inplace()`：在原 DOT 上打补丁（保持原样式，仅加颜色/tooltip）。
- `render_thread_frequency_png()` 等：统计图生成。
- `choose_time_analysis_output_dir()`：定位时间分析输出目录。

## 2.6 文档/脚本
- `FULL_FEATURE_GUIDE_CN.md`：老版综合说明，已更新配置目录路径。
- `文档/调度算法/调度算法策略与插桩设计.md`：调度策略/插桩方案。
- `文档/系统架构/`：本系列文档，供大模型/新人快速理解架构。

依赖关系示意：
```
legacy ──> (配置/中间结果)
   │
   ├── ui/gui ──> 调度算法 (scheduler)
   │               └── 时间分析 (time_analysis) / 最长路径数据
   └── viewer
```
