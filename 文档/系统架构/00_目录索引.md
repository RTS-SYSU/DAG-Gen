# 系统架构文档索引

本目录面向需要快速理解 **MycallyPlus** 的开发者与大模型。建议按顺序阅读，以获得从宏观到细节的完整上下文。

| 顺序 | 文档 | 说明 |
| ---- | ---- | ---- |
| 01 | 《01_概要设计.md》 | 工具定位、核心流程、整体组件关系图（文字版）。 |
| 02 | 《02_模块与依赖.md》 | generation/ui/visualization/time_analysis/scheduler 等模块职责、依赖、关键入口。 |
| 03 | 《03_GUI按键与交互.md》 | 图形化界面按键、状态区、子功能联动，描述用户操作到底层命令的映射。 |
| 04 | 《04_数据流与存储机制.md》 | 配置/中间结果目录结构、文件命名规则、策略输出目录、调试快照位置。 |
| 05 | 《05_生成流水线.md》 | legacy 解析、条件节点、线程补边、debug 快照等细节。 |
| 06 | 《06_时间分析与调度.md》 | 时间分析插桩流程、调度策略、最长路径插桩、输出目录。 |
| 07 | 《07_开发与测试指南.md》 | 常用命令、CLI/GUI 启动、示例（time_analysis.c）运行步骤、调试建议。 |

此外，可结合已有文档：
- `文档/GUI_按键功能说明.md`（旧版 GUI 描述，可作为补充）
- `文档/调度算法/调度算法策略与插桩设计.md`（与 06 章节互补）
- `文档/FULL_FEATURE_GUIDE_CN.md`（细节操作指南）

若需图示，可在 `assets/` 子目录补充架构图或流程图，并在各文档中引用。***
