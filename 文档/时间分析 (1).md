# 📝 时间分析

## 📌 1. 功能名称  
**时间分析（Time Analysis）**

为 C 语言项目执行如下功能：

1. 根据 `mycalls_meta.json` 中的函数位置对源文件进行自动插桩  
2. 自动生成插桩后的 C 文件  
3. 自动编译（gcc）和运行程序  
4. 收集每个函数的执行时间  
5. 将执行时间写回 `mycalls_meta.json`  
6. 输出一张函数执行时间报告（Markdown 表格）  

---

## 📌 2. 输入

### **2.1 meta.json 内容**
字段至少包含：

```json
{
  "nodes": [
    {
      "func": "foo",
      "file": "src/a.c",
      "line": 123,
      "extern": 1
    }
  ]
}
```

说明：

- `func`：函数名（可直接用于统计）  
- `file`：该函数的源文件  
- `line`：函数定义所在行  
- `extern==1`：需要插桩的函数  

---

## 📌 3. 输出

### **3.1 插桩后的 C 文件**
路径示例：

```
build_time_analysis/instrumented_xxx.c
```

### **3.2 运行时代码**
自动复制：

```
time_stat.c
time_stat.h
```

### **3.3 编译生成的可执行程序**

```
build_time_analysis/app
```

### **3.4 时间统计结果**

```
build_time_analysis/time_result.json
```

示例：

```json
{
  "functions": [
    {
      "name": "foo",
      "total_ns": 100000,
      "count": 10,
      "avg_ns": 10000,
      "max_ns": 15000,
      "min_ns": 9000
    }
  ]
}
```

### **3.5 报表 time_report.md**

```
| Function | Count | Total (ns) | Avg (ns) | Max (ns) | Min (ns) |
|---------|-------|------------|----------|----------|----------|
| foo     | 10    | 100000     | 10000    | 15000    | 9000     |
```

### **3.6 回写到 meta.json**

对 `extern==1` 的函数新增字段：

```
"time_ns": <total_ns>
```

---

## 📌 4. 插桩规则（Codex 按此生成代码）

### **4.1 插桩范围**
- 仅对 `extern==1` 的函数插桩  
- 函数由 `file` 和 `line` 信息确定  
- 不支持递归  

---

### **4.2 插桩点：函数起始位置**

在函数体 `{` 之后的**第一条语句**前插入：

```c
uint64_t __ta_start_<func> = now_ns();
```

---

### **4.3 插桩点：所有 return 前**

每当遇到 `return`（不论形式）前插入：

```c
time_account("<func>", now_ns() - __ta_start_<func>);
```

---

### **4.4 无 return 的情况**

在函数最后 `}` 前一行插入：

```c
time_account("<func>", now_ns() - __ta_start_<func>);
```

---

### **4.5 函数体范围（大括号匹配）**

函数定义行号已给出  
从该行开始往下找到第一个 `{` → 函数体起点  
然后使用大括号计数法匹配函数体结束位置  

---

## 📌 5. 运行时代码（time_stat.c / time_stat.h）

要求 Codex 生成：

1) `now_ns()`：基于 `clock_gettime(CLOCK_MONOTONIC)` 的纳秒计时  
2) `time_account(name, dur)`：线程安全累计  
3) 自动注册 `atexit()` 输出 `time_result.json`  

输出格式如下：

```json
{
  "functions": [
    {"name": "...", "total_ns":..., "count":..., "avg_ns":..., "max_ns":..., "min_ns":...}
  ]
}
```

---

## 📌 6. 自动编译 & 自动运行

使用 gcc：

```
gcc instrumented_*.c time_stat.c -O2 -std=c11 -pthread -o app
```

（旧 Linux 需加 `-lrt`）

运行：

```
./app
```

生成 `time_result.json`。

---

## 📌 7. 回填 meta.json

Codex 要实现：

```python
for node in meta["nodes"]:
    if node["extern"] == 1:
        node["time_ns"] = time_result[node["func"]]["total_ns"]
```

最后保存回原来的 meta.json。

---

## 📌 8. 生成报表（Markdown 格式）

功能：

- 按 total_ns 排序  
- 输出 Markdown 表格  
- 文件路径：`build_time_analysis/time_report.md`

示例表格：

```
| Function | Count | Total (ns) | Avg (ns) | Max (ns) | Min (ns) |
|---------|-------|------------|----------|----------|----------|
| foo     | 10    | 100000     | 10000    | 15000    | 9000     |
```

---

## 📌 9. 整体流程（伪代码）

```
load meta.json
group functions by source file
for each C file:
    read file
    apply instrumentation based on func line numbers
    write instrumented_<file>.c

copy time_stat.c / time_stat.h

gcc instrumented_files + time_stat.c → app
run app → generates time_result.json

merge results back into meta.json (add time_ns field)
generate time_report.md
```
