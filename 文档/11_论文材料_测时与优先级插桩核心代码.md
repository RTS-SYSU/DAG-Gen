# 测时与优先级插桩核心代码

这份材料用于喂给 GPT，目标是让它根据 ScratchDAG 的真实实现，生成论文中的“测时机制”和“优先级插桩机制”说明。内容只保留最核心的代码和最少的解释。

## 1. 测时机制

ScratchDAG 的段级测时本质上是：

```c
start = now_ns();
/* 被测代码段 */
end = now_ns();
duration = end - start;
```

其中 `now_ns()` 的核心实现如下：

```c
static uint64_t now_ns(void) {
    struct timespec ts;
    clock_gettime(CLOCK_MONOTONIC, &ts);
    return (uint64_t)ts.tv_sec * 1000000000ULL + (uint64_t)ts.tv_nsec;
}
```

段开始时记录开始时间：

```c
static __thread uint64_t tls_t0_ns = 0;

void segtrace_begin(const char *seg_id) {
    tls_t0_ns = now_ns();
}
```

段结束时再次取时间，并计算持续时间：

```c
void segtrace_end(const char *seg_id) {
    uint64_t t1 = now_ns();
    uint64_t dur = (t1 >= tls_t0_ns) ? (t1 - tls_t0_ns) : 0;
}
```

实际代码中，结果会写入 CSV 文件：

```c
fprintf(tls_fp, "%d,\"%s\",%llu,%llu,%llu\n",
        (int)tid,
        seg_id ? seg_id : "",
        (unsigned long long)tls_t0_ns,
        (unsigned long long)t1,
        (unsigned long long)dur);
```

因此，ScratchDAG 的测时机制可以概括为：

1. 在代码段入口调用 `segtrace_begin(seg_id)`
2. 在代码段出口调用 `segtrace_end(seg_id)`
3. 内部通过两次 `clock_gettime(CLOCK_MONOTONIC, ...)` 获取开始和结束时间
4. 用 `end - start` 得到该段执行时间，单位为纳秒
5. 将线程 ID、段 ID、开始时间、结束时间、持续时间写入 trace 文件

## 2. 优先级插桩机制

ScratchDAG 的优先级插桩调用形式为：

```c
l1_set_thread_prio_fifo(76);
```

这个函数不是系统自带函数，而是项目里定义的包装函数。其核心实现如下：

```c
static inline void l1_set_thread_prio_fifo(int prio) {
    struct sched_param sp;
    memset(&sp, 0, sizeof(sp));
    sp.sched_priority = prio;
    int rc = pthread_setschedparam(pthread_self(), SCHED_FIFO, &sp);
    if (rc != 0) {
        fprintf(stderr, "L1_PRIO_SET_FAILED rc=%d errno=%d (%s)\n",
                rc, errno, strerror(errno));
    }
}
```

它的含义是：

1. 构造 `sched_param`
2. 把 `sched_priority` 设为给定优先级，例如 `76`
3. 调用 `pthread_setschedparam`
4. 将当前线程调度策略设置为 `SCHED_FIFO`
5. 将当前线程优先级设置为指定值

因此，这一行：

```c
l1_set_thread_prio_fifo(76);
```

本质上等价于：

```c
struct sched_param sp;
memset(&sp, 0, sizeof(sp));
sp.sched_priority = 76;
pthread_setschedparam(pthread_self(), SCHED_FIFO, &sp);
```

## 3. 插桩后的代码形式

如果同时进行测时和优先级插桩，一个典型代码段可以写成：

```c
SEG_BEGIN("seg_1");
l1_set_thread_prio_fifo(76);
compute();
SEG_END("seg_1");
```

其执行逻辑是：

1. 在段开始时记录开始时间
2. 设置当前线程的 FIFO 实时优先级
3. 执行该段计算代码
4. 在段结束时记录结束时间并计算段执行时间
