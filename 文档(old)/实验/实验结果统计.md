# 通用实验结果统计方法

本文档描述一套可复用的实验结果统计流程，适用于 VM / RK3588 等平台，及不同算法分组（如 `cpf/lpf/heft/zhao2020`）。

## 1. 输入是什么

统计输入是实验运行后产生的 `summary.json` 文件集合。  
建议目录形态：

- `.../<平台或分组>/<suite>/<run>/summary.json`
- 例如：`.../zhang1(algo_5)/web_tasks/2026-03-16T11-07-58+08-00_ws100_r100/summary.json`

`summary.json` 至少应包含：

- 元信息：`created_at`、`work_scale`、`repeats`、`cpu_set`、`cores_per_task`
- 统计值：`baseline.stats.{mean_s,max_s,min_s,n}`、`prio.stats.{mean_s,max_s,min_s,n}`
- 对比值：`delta_mean_s`、`improvement_ratio`
- 可选算法识别信息：`baseline/prio.c_file` 或 `baseline/prio.compile_cmd`

## 2. 输出是什么

建议输出到统一目录 `tables/`，包含：

- 分组 CSV：`runtime_results_<分组>.csv`
- 全量 CSV：`runtime_results_all.csv`
- 展示用 Markdown：`runtime_results_by_platform.md` 或 `runtime_results_by_suite.md`

如果按 `zhang1/zhang2/zhang3` 分组，则典型输出为：

- `runtime_results_zhang1(algo_5).csv`
- `runtime_results_zhang2(algo_5).csv`
- `runtime_results_zhang3(algo_5).csv`
- `runtime_results_all.csv`
- `runtime_results_by_platform.md`

## 3. 如何得到结果（流程）

1. 准备输入目录：确认所有 run 目录都有 `summary.json`。  
2. 执行统计脚本：递归扫描输入目录、提取字段、写出 CSV/Markdown。  
3. 校验输出：检查文件更新时间、行数、关键 run 是否出现。  
4. 发布结果：将 `tables/` 下文件用于对比分析或汇报。

示例命令（仓库根目录执行）：

```bash
python3 "/home/chove/Desktop/ScratchDAG/experiment/algo5（虚拟机实验结果统计）/scripts/build_algo5_runtime_results.py"
```

## 4. 结果格式（CSV 规范）

推荐列顺序：

`platform,算法名,work_scale,repeats,baseline_mean_s,prio_mean_s,improvement_ratio,delta_mean_s,baseline_total_s,prio_total_s,baseline_min_s,baseline_max_s,prio_min_s,prio_max_s,cpu_set,cores_per_task,created_at,out_dir`

字段口径：

- `baseline_total_s = baseline_mean_s * baseline.stats.n`
- `prio_total_s = prio_mean_s * prio.stats.n`
- `delta_mean_s = prio_mean_s - baseline_mean_s`
- `improvement_ratio = (baseline_mean_s - prio_mean_s) / baseline_mean_s`

`算法名` 识别建议：

1. 优先从 `c_file` 的 `effective_line_merge/<algo>/...` 提取  
2. 回退从 `compile_cmd` 中 `/baseline/<algo>/` 或 `/prio/<algo>/` 提取

## 5. 输出质量检查

最少检查这 4 项：

1. 每个输入 run 在 CSV 中有且仅有一条记录。  
2. `repeats` 与 `stats.n` 一致（或符合预期）。  
3. `improvement_ratio` 正负号符合实际性能变化。  
4. `created_at`、`out_dir` 能唯一定位原始 run。

## 6. 常见问题

### 6.1 权限导致无法移动/覆盖输入目录

如果结果目录由 `root` 生成，你可能无法整理目录。可改回当前用户：

```bash
sudo chown -R chove:chove "/home/chove/Desktop/ScratchDAG/tools/runtime_compare/实验结果"
chmod -R u+rwX,g+rwX "/home/chove/Desktop/ScratchDAG/tools/runtime_compare/实验结果"
```

### 6.2 预览显示小数被截断

若 CSV 预览插件把数值格式化为 2 位，可在工作区设置中关闭数值格式化：

```json
{
  "csv-preview.formatValues": "never"
}
```
