## 4. 当前统计口径（已实现）

- CSV 列顺序：
  `platform,算法名,work_scale,repeats,baseline_mean_s,prio_mean_s,improvement_ratio,delta_mean_s,baseline_total_s,prio_total_s,baseline_min_s,baseline_max_s,prio_min_s,prio_max_s,cpu_set,cores_per_task,created_at,out_dir`
- `算法名` 识别规则：
  - 优先从 `baseline/prio.c_file` 的 `effective_line_merge/<algo>/...` 提取
  - 回退从 `baseline/prio.compile_cmd` 中路径提取
- `total_s` 计算规则：`mean_s * n`

## 5. 常见问题

### 5.1 无法移动源结果目录（root 权限）

如果 `tools/runtime_compare/实验结果` 下很多子目录是 `root:root`，你可能无法随意移动。可改回当前用户：

```bash
sudo chown -R chove:chove "/home/chove/Desktop/ScratchDAG/tools/runtime_compare/实验结果"
```

可选再放开写权限：

```bash
chmod -R u+rwX,g+rwX "/home/chove/Desktop/ScratchDAG/tools/runtime_compare/实验结果"
```
