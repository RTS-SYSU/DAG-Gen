# 06. 时间分析与调度

## 6.1 时间分析 (time_analysis.py)
### 输入
- `mycalls_meta_internal.json`（来自 `中间结果/<base>/生成dag图/debug/`）
- 源项目（包含 `*.c` 及依赖头文件）

### 步骤
1. **解析 CallSite**：`load_call_sites()` → `CallSite(file,line,col,func,raw_key)`
2. **复制项目**：到 `中间结果/<base>/时间分析/<project>/`
3. **插桩**：在匹配的 `file:line` 插入 `now_ns()` 计时代码（BEGIN/END）
4. **编译 & 运行**：`gcc -O2 -std=c11 -pthread …` → 生成 `app` 并执行
5. **输出**：
   - `time_result.json`（每个节点 total_ns/count/avg/max/min）
   - `thread_trace.json`（每次调用 start/dur，可用于甘特图）
   - `thread_time_summary.json`（回写至 `mycalls_meta_internal.json` 同目录）
   - 日志：`中间结果/<base>/生成dag图/debug/time_analysis.log`

### 注意
- 支持 `--extern-only`（仅内部节点）；
- 插桩失败原因（缺失文件、控制语句未完整匹配）会记录在 log 中；
- 若需要差异分析，可在 `时间分析_lp` 目录运行变体。

## 6.2 调度算法 (scheduler.py)
### 输入
- `dag.dot`（或 `dag_highlight.dot`）——可从 `中间结果/<base>/生成dag图/` 获得
- `time_result.json`——来自时间分析
- `longest_path.json`——由 `scheduler` 或 GUI 生成
- `mycalls_meta_internal.json`——用于插桩/线程映射

### 功能
1. **权重计算**：从 `time_result.json` 取 `total_ns`，缺失设 0。
2. **最长路径**：`longest_path_dag()`，拓扑 + DP；有环报错。
3. **DOT 高亮**：`highlight_dot_inplace()` 在原 DOT 上追加属性（红色边、高亮节点、tooltip=total_ns）。
4. **统计图**：`render_thread_frequency_png()`、`render_thread_total_time_png()`；路径在时间分析目录。
5. **输出目录**：`中间结果/<base>/调度算法/<strategy>/`，文件：
   - `dag_highlight.dot/png`
   - `schedule.json`（路径、优先级、总权重）
   - `schedule.txt`（摘要）

### 策略扩展
- Longest-Path Priority（基线）
- Criticality×Cost、ASAP/ALAP、线程优先、Round-Robin 等（可在 GUI 子功能中扩展）
- 优先级映射可配置，例如：关键路径=80、次关键=70、普通=50；在 `schedule.json` 中记录实际值。
- 线程归属：默认用节点名前缀；如需精准可从 `mycalls_meta_internal.json` 获取 `file` 信息。

## 6.3 最长路径插桩子功能
（详见《文档/调度算法/调度算法策略与插桩设计.md》，此处摘要）
- 输入：源代码、`mycalls_meta_internal.json`、基线 `time_result.json`、`longest_path.json`
- 流程：仅对 `path` 中的节点插桩 → 编译运行 → 输出 `time_result_longest.json`
- 对比：生成 `longest_path_compare.{json,txt}`（插桩前/后总耗时、节点耗时差异）
- 输出目录：`中间结果/<base>/时间分析_lp/<project>/` + `中间结果/<base>/调度算法/longest_path_compare.*`
- key 命名：推荐追加 `_lp` 后缀，保留基线数据

## 6.4 示例（time_analysis 工程）
- `time_result.json`：`mycallyplus_v1/中间结果/time_analysis/时间分析/time_analysis/time_result.json`
- `thread_trace.json`：同目录
- `longest_path.json`：`mycallyplus_v1/中间结果/time_analysis/调度算法/longest_path/longest_path.json`
- 插桩对比输出：`中间结果/time_analysis/时间分析_lp/time_analysis/` + `中间结果/time_analysis/调度算法/longest_path_compare.*`
