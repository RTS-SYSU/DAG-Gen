# 05. 生成流水线（legacy）

## 5.1 CLI 概览
`python -m mycallyplus_v1.generation.legacy [options] <expand...>`

常用参数：
- `--threads-only` / `--conditions-only` / `--extern-only`
- `--output-base <path>`（默认 `mycallyplus_v1`）
- `--source-file <C 源>`（用于 extern 区分、mycalls_meta 文件路径映射）
- `--export-txt <path>`（circle.txt）
- `--smart` / `--clean` / `--force`
- `--debug`

## 5.2 解析流程
1. **读取 expand**：逐行正则匹配
   - 函数声明：`;; Function ...`
   - `call`：提取目标函数、源位置信息
   - `symbol_ref`：记录引用
2. **mycalls & myinfo**
   - `mycalls`：按调用顺序记录 call 节点（包含条件前缀、线程编号等）
   - `myinfo`：记录线程 create/join 关系（thread_id → task_function、join_node → thread_id），用于补边。
3. **条件前缀识别**
   - 预读 `control_prefix`，识别 if/while/switch 的跳转区块，给 `mycalls` 添加 `if/`、`while/`、`switchK/` 前缀。
4. **线程补边**
   - `thread_map.resolve_join_edges()` 根据 `myinfo` 生成 tail → join 边。
5. **调试快照**
   - `post_parse.json`、`control_prefix.json`、`post_callee_info.json`、`threads.json` 等写至 `中间结果/<base>/生成dag图/debug/`

## 5.3 DOT 生成
- `full_call_graph()`：遍历 `functions`，按 `mycalls` 连边，处理条件节点（虚线）、线程补边。
- `conditions_call_graph()`：只输出条件节点链。
- `dump_path()`：caller/callee 子图。
- 输出位置：
  - `中间结果/<base>/配置文件/<base>_threads.dot`
  - `中间结果/<base>/配置文件/<base>_full.dot`
  - `中间结果/<base>/配置文件/<base>.dot`（默认）

## 5.4 circle.txt 导出
- 参数 `--export-txt` / GUI“生成配置文件”按钮。
- 内容包含互斥锁/信号量节点→编号/源码位置，供互斥锁/信号量图使用。
- 输出：`中间结果/<base>/配置文件/circle.txt`

## 5.5 关联文件
- `functions_full.json`：完整函数表（debug）
- `call_src_full.json`：节点 → 源文件简名映射
- `mycalls_meta.json` / `mycalls_meta_internal.json`：节点 → 源位置信息/extern 标记；时间分析输入依赖它们
- `thread_time_summary.json`：时间分析回写每个线程耗时

## 5.6 注意事项
- base 名推导：去掉 `.233r.expand` 与 `.c/.cpp` 后缀。
- 所有写操作仅针对 `中间结果/<base>/...`，旧 `配置文件/<base>/` 仅保留读取兼容。
- 若 GUI 运行在 Windows，需要预装 Graphviz，`dot` 命令可用。

生成阶段完成后，可通过 GUI/Viewer 打开 `中间结果/<base>/配置文件/`，或继续执行时间分析/调度策略。***
