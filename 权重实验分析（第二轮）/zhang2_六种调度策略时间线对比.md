# zhang2 六种调度策略执行时间线对比（第二轮）

**数据来源**: 本目录 `zhang2_all_traces.json`（`run_all_traces.py` 单次采集）。  
**方法**: `实验文档/约定术语.md` §调度 Trace 分析法。  
**实验参数**: ws=100, cpu=6,7（2 核）, zhang2.c（`权值调整实验.md` 第一轮权重 C1~C15）。

### Phase 分析

- **Phase 1 (0~79 ms)**: main:C8 与 worker 启动初期重叠，2 核上竞争开始。
- **Phase 2 (~79~202 ms)**: main(C9,C10)、c0、c1:C4、c2:C1 多线程 CFS 轮转。
- **Phase 3 (~202~406 ms)**: c1:C5、c2:C2、main(C11,C12) 三任务争 2 核；main:C12 约 **328 ms** 结束，随后 `sem_post(s3)`。
- **Phase 4 (~406~680 ms)**: c2:C3 与 main(C13,C14) 并行推进。
- **Phase 5 (~680~684 ms)**: join c2 后 main:C15。

**要点**: CFS 下 **c2:C3 从 406 ms 开始**，仍早于各 SCHED_FIFO 方案（见文末表）。

## 核心结论（第二轮）

### c2:C3 起止（决定总时间的主导因素）

| 算法 | c2:C3 开始 (ms) | c2:C3 结束 (ms) | 总时间 (ms) | vs CFS |
|------|----------------|-----------------|-------------|--------|
| CFS | 406.0 | 631.0 | 684.3 | 基准 |
| wcet_first | 494.3 | 718.9 | 722.7 | 慢约 5.6% |
| FIFO | 496.9 | 721.7 | 725.4 | 慢约 6.0% |
| heft | 510.7 | 735.3 | 739.1 | 慢约 8.0% |
| zhao2020 | 524.8 | 749.4 | 753.2 | 慢约 10.1% |
| t_level | 557.0 | 781.3 | 785.1 | 慢约 14.7% |

### 与第一轮对比的提示

- **不要**把第一轮 `zhang2_六种调度策略时间线对比.md` 的数字与本轮混用；横向对比请用各自目录下的 `zhang2_all_traces.json`。
- 定性结论仍可与 `权值调整实验.md` 一致：**zhang2 的 sem 链 + 多就绪线程争 2 核**时，CFS 时间片往往能更早让 **c2:C3** 起跑；SCHED_FIFO 配方不同会推迟 `sem_post(s3)` 或压低 c2 的 CPU 份额。
- **本轮** wcet_first / FIFO 名次好于第一轮中某些算法，属于**同一方法下的单次采样差异**，非 Trace 表抄错；复现可多跑几次对 `total` 取统计量。
